# 前端字体与字号规范

本文档用于说明 `agentinsight-eufy` 前端当前实际使用的字体、字号层级与排版规则。它不是理想化设计稿，而是基于现有实现整理出的可执行基线，便于后续继续统一首页、项目页、指标页和报告页的视觉语言。

## 1. 适用范围

- 当前前端工作台
- 首页 `/projects`
- 项目页 `/projects/:id`
- 指标页 `/projects/:id/metrics`
- 报告页 `/projects/:id/report`

## 2. 当前字体栈

全站当前统一使用同一套字体栈：

```css
font-family: "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif;
```

实际表现一般为：

- 英文优先使用 `Segoe UI`
- 中文优先使用 `PingFang SC`
- Windows 环境下中文也可能回退到 `Microsoft YaHei`
- 最终回退到系统 `sans-serif`

## 3. 基础排版基线

- 根字号默认按浏览器 `16px` 计算
- 默认正文行高：`1.5`
- 默认字重：`400`
- 英文功能标题大量使用全大写
- 英文功能标题通常配合较高字重和正向字间距
- 大标题通常配合负字间距，减弱松散感

## 4. 字号层级

### H0 Hero Title

用于极少数页面级大标题。

- 选择器：`.section-heading--hero .section-heading__title`
- 字号：`clamp(2rem, 3vw, 2.4rem)`
- 对应像素：`32px ~ 38.4px`
- 字重：继承当前标题默认字重
- 字间距：`-0.03em`

说明：
- 当前首页主标题已被移除，但样式定义仍在
- 后续若恢复页面级大标题，可继续使用这一层级

### H0 Home Intro Title

用于首页欢迎语式大标题。

- 选择器：`.home-intro__title`
- 字号：`clamp(2rem, 3vw, 2.5rem)`
- 对应像素：`32px ~ 40px`
- 字重：`650`
- 字间距：`-0.04em`

说明：
- 当前首页欢迎语已删除
- 这一层级目前属于保留样式，不建议在新页面继续扩散

### H1 Section Title

用于通用模块标题。

- 选择器：`.section-heading__title`
- 字号：`clamp(1.3rem, 2vw, 2rem)`
- 对应像素：`20.8px ~ 32px`
- 字重：继承当前标题默认字重
- 字间距：默认

适用场景：

- 页面中的核心模块标题
- 项目内较重要的一级信息区块

### H2 Accent Section Title

用于首页这类强引导分区标题，例如 `NEXT ACTION`、`CONTINUE WORKING`、`RECENT ACTIVITY`。

- 选择器：`.section-heading--accent-title .section-heading__title`
- 字号：`1rem`
- 对应像素：`16px`
- 字重：继承标题默认字重
- 字间距：`0.08em`
- 大小写：`uppercase`
- 颜色：品牌蓝 `var(--accent)`

说明：
- 这是“功能型分区标题”，不是内容标题
- 它的识别性来自颜色、字重和字间距，而不是字号

### H2 Home Section Title

用于首页编号分区标题。

- 选择器：`.home-section__title`
- 字号：`1rem`
- 对应像素：`16px`
- 字重：`700`
- 字间距：`0.06em`
- 颜色：品牌蓝 `var(--accent)`

说明：
- 这一层级本质上与首页英文功能标题接近
- 更偏“导航分区”而不是“阅读标题”

### H3 Card Primary Title

用于重点卡片中的主要内容标题。

- 选择器：`.next-action-banner__main h3`
- 字号：`1.55rem`
- 对应像素：`24.8px`
- 字重：继承当前标题默认字重
- 字间距：`-0.03em`
- 行高：`1.08`

适用场景：

- `NEXT ACTION` 卡片主标题
- 需要强视觉聚焦的单一任务标题

### H4 List Item Title

用于列表项标题、活动标题、项目名。

- 选择器：
  - `.work-list__header strong`
  - `.activity-list__main strong`
  - `.home-work-list__header strong`
  - `.home-activity-list__main strong`
- 字号：`0.96rem`
- 对应像素：`15.36px`
- 字重：浏览器默认 `strong` 字重

适用场景：

- 项目列表名称
- 动态列表标题
- 普通卡片内容标题

## 5. 辅助文字层级

### Eyebrow / Caption

用于极轻量的上方说明文字。

- 选择器：`.section-heading__eyebrow`
- 字号：`12px`
- 字重：`700`
- 字间距：`0.08em`
- 大小写：`uppercase`

Hero 版 eyebrow：

- 选择器：`.section-heading--hero .section-heading__eyebrow`
- 字号：`11px`
- 字重：`600`
- 字间距：`0.12em`
- 大小写：`uppercase`

首页 intro eyebrow：

- 选择器：`.home-intro__eyebrow`
- 字号：`11px`
- 字重：`700`
- 字间距：`0.12em`
- 大小写：`uppercase`

### Body

用于说明文字、简介、段落型信息。

- 默认正文：继承 `16px`
- `NEXT ACTION` 描述：
  - 选择器：`.next-action-banner__main p`
  - 字号：`0.94rem`
  - 对应像素：`15.04px`
  - 行高：`1.55`

### Meta

用于时间、阶段、标签说明、用户描述等次级信息。

- 常用字号：`0.88rem`
- 对应像素：`14.08px`

当前主要位置：

- `.next-action-banner__meta`
- `.work-list__subline`
- `.work-list__progress-head span`
- `.work-list__meta`
- `.activity-list__meta`
- 对应的 `home-*` 版本

### Small Meta

用于更轻的信息标签和总览说明。

- 概览标题 `.overview-strip__item span`
  - 字号：`11px`
  - 字重：`600`
  - 字间距：`0.06em`

- `NEXT ACTION` 右侧阶段说明 `.next-action-banner__stage span`
  - 字号：`0.84rem`
  - 对应像素：`13.44px`

## 6. 数据与数字展示

### Summary Number

用于首页 overview strip 的数量信息。

- 选择器：`.overview-strip__item strong`
- 字号：`1.34rem`
- 对应像素：`21.44px`
- 字重：`650`
- 字间距：`-0.02em`
- 数字特性：`font-variant-numeric: tabular-nums`

### Summary Time

用于首页 overview strip 中的时间信息。

- 选择器：`.overview-strip__item--wide strong`
- 字号：`1.02rem`
- 对应像素：`16.32px`
- 字间距：`-0.01em`

说明：
- 计数项和时间项刻意区分层级
- 时间不应比计数更抢视觉重心

## 7. 当前推荐使用规则

- 页面级大标题尽量少用，首页不再堆叠欢迎式文案
- 英文分区标题统一使用蓝色、小字号、全大写、高字间距
- 内容标题和功能标题不要混用同一层级
- 数值信息应比标签更重，但不要比主标题更重
- 时间、状态、阶段、ID 统一归入 `Meta` 层，不与主标题抢层级
- 同一屏内标题层级建议控制在 `2~3` 层，不再继续细分

## 8. 后续优化建议

如果后续要进一步专业化当前工作台，建议按下面方向继续收敛：

- 为中文和英文建立更明确的双语字体策略，而不是完全共用系统回退
- 建立固定的标题 token，例如 `display / section / card / list / meta`
- 减少 `clamp()` 的使用范围，只保留在真正需要强响应式缩放的大标题上
- 把首页、项目页、指标页、报告页的标题系统统一到同一套 token
