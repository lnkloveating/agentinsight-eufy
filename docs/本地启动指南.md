# AgentInsight eufy 本地启动指南

本文档适用于 Windows + PowerShell 的本地开发环境。

## 1. 目录说明

项目根目录：

```text
D:\feishu\agentinsight-eufy
```

前端位于：

```text
src\frontend
```

后端位于：

```text
src\backend
```

默认服务地址：

```text
前端：http://localhost:5173
后端：http://localhost:8000
Swagger：http://localhost:8000/docs
```

## 2. 前置环境

需要安装：

- Node.js 20 或更高版本
- npm
- Python 3.11 或更高版本
- PowerShell

检查版本：

```powershell
node --version
npm --version
python --version
```

## 3. 首次安装

在项目根目录执行：

```powershell
cd D:\feishu\agentinsight-eufy
npm install
```

创建并初始化后端虚拟环境：

```powershell
cd D:\feishu\agentinsight-eufy\src\backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
```

如果 PowerShell 禁止执行激活脚本，可以仅对当前终端临时放开：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
```

## 4. 配置后端环境变量

后端从 `src\backend\.env` 读取配置。

如果项目根目录已经有 `.env`，可以复制一份到后端目录：

```powershell
cd D:\feishu\agentinsight-eufy\src\backend
Copy-Item ..\..\.env .env -Force
```

如果没有根目录 `.env`，可以从示例文件创建：

```powershell
Copy-Item ..\..\.env.example .env
```

本地至少应确认以下配置存在：

```dotenv
APP_ENV=development
API_HOST=0.0.0.0
API_PORT=8000
DATABASE_URL=sqlite+aiosqlite:///./data/agentinsight.db
AUTO_CREATE_SCHEMA=true
FRONTEND_ORIGINS=["http://localhost:5173"]
```

如果需要真实模型调用，再在 `.env` 中配置对应的 API Key。不要把 API Key 写入 `.env.example` 或提交到 Git。

## 5. 初始化数据库

每次首次安装，或数据库迁移发生变化后，在后端目录执行：

```powershell
cd D:\feishu\agentinsight-eufy\src\backend
.\.venv\Scripts\Activate.ps1
alembic upgrade head
```

数据库默认会使用：

```text
src\backend\data\agentinsight.db
```

## 6. 启动后端

打开一个 PowerShell 窗口：

```powershell
cd D:\feishu\agentinsight-eufy\src\backend
.\.venv\Scripts\Activate.ps1
python -m app.main
```

成功后保持该窗口运行。后端接口地址为：

```text
http://localhost:8000/api/v1
```

验证后端：

```powershell
Invoke-WebRequest http://localhost:8000/api/v1/health -UseBasicParsing
```

也可以直接打开 Swagger：

```text
http://localhost:8000/docs
```

## 7. 启动前端

打开第二个 PowerShell 窗口：

```powershell
cd D:\feishu\agentinsight-eufy
npm run frontend:dev
```

成功后打开：

```text
http://localhost:5173
```

前端默认请求：

```text
http://localhost:8000/api/v1
```

如果需要修改后端地址，可以在前端环境变量中设置：

```powershell
$env:VITE_API_BASE_URL = "http://localhost:8000/api/v1"
npm run frontend:dev
```

## 8. 推荐启动顺序

每次开发时按以下顺序启动：

1. 启动后端并确认 `/api/v1/health` 返回成功。
2. 启动前端并打开 `http://localhost:5173`。
3. 在浏览器开发者工具中确认请求发往 `localhost:8000`。
4. 打开项目工作台，确认项目、Evidence、Innovation 和 SSE 时间线来自真实后端。

## 9. 停止服务

在运行服务的 PowerShell 窗口按：

```text
Ctrl + C
```

分别停止前端和后端即可。

如果窗口已经关闭但端口仍被占用，可以查找进程：

```powershell
netstat -ano | Select-String ":5173|:8000"
```

再根据最后一列 PID 结束对应进程：

```powershell
Stop-Process -Id <PID>
```

## 10. 常见问题

### `ModuleNotFoundError: No module named 'av'`

通常是没有激活项目的后端虚拟环境，或者依赖安装到了其他 Python 环境。执行：

```powershell
cd D:\feishu\agentinsight-eufy\src\backend
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
python -c "import av; print(av.__version__)"
```

确认 `import av` 成功后，再执行：

```powershell
python -m app.main
```

### 前端页面能打开，但接口请求失败

确认后端已启动，并检查：

```powershell
Invoke-WebRequest http://localhost:8000/api/v1/health -UseBasicParsing
```

同时确认前端环境变量没有指向错误地址：

```text
VITE_API_BASE_URL=http://localhost:8000/api/v1
```

### 端口 8000 已被占用

查看占用进程：

```powershell
netstat -ano | Select-String ":8000"
```

停止对应进程，或修改后端 `.env` 中的 `API_PORT`，并同步修改前端的 `VITE_API_BASE_URL`。

### 前端仍显示旧的 Mock 数据

确认 `.env` 中没有开启 Mock 回退：

```dotenv
VITE_ENABLE_MOCK_FALLBACK=false
```

修改后重启前端开发服务器。
