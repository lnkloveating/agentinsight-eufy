# 前端视觉基础规范

本文档基于 `agentinsight-eufy` 当前前端实现整理，用于约束后续页面设计与样式迭代，重点覆盖：

- 颜色
- 圆角
- 间距
- 阴影
- 边框
- 背景

它与 [字体与字号规范.md](./字体与字号规范.md) 配套使用。

## 1. 文档定位

这不是抽象品牌手册，而是当前工作台的实现基线。

目标只有一个：

让首页、项目页、指标页、报告页持续保持同一套“研究工作台”气质，而不是逐渐滑向：

- 通用后台
- AI 聊天首页
- 大屏看板
- 营销型卡片界面

## 2. 当前设计气质

当前视觉方向应稳定在以下范围内：

- 浅底
- 冷静
- 专业
- 结构清楚
- 弱装饰

不追求：

- 炫技 AI 感
- 强烈渐变秀场
- 夸张投影
- 彩色大卡片瀑布流

## 3. 颜色系统

### 3.1 核心变量

当前在 [global.css](/D:/feishu/agentinsight-eufy/src/frontend/src/styles/global.css:11) 中定义的核心颜色变量如下：

```css
--bg-panel: rgba(255, 255, 255, 0.82);
--bg-panel-strong: rgba(255, 255, 255, 0.94);
--border-subtle: rgba(21, 54, 91, 0.12);
--border-strong: rgba(21, 54, 91, 0.2);
--text-main: #18202a;
--text-muted: #5f6c7b;
--accent: #1f5eff;
--accent-soft: rgba(31, 94, 255, 0.12);
--warning: #c47912;
--warning-soft: rgba(196, 121, 18, 0.12);
--danger: #bf4535;
--danger-soft: rgba(191, 69, 53, 0.12);
--success: #1d7f5c;
--success-soft: rgba(29, 127, 92, 0.12);
```

### 3.2 颜色角色

#### 主文本

- `--text-main: #18202a`
- 用于主要标题、正文、重点信息

#### 次文本

- `--text-muted: #5f6c7b`
- 用于时间、阶段、说明、辅助标签

#### 主强调色

- `--accent: #1f5eff`
- 用于：
  - 选中态
  - 英文功能标题
  - 主要按钮
  - 关键进度
  - 一级导航激活态

#### 主强调浅底

- `--accent-soft: rgba(31, 94, 255, 0.12)`
- 用于：
  - badge 背景
  - 选中态弱底色
  - 轻 hover

#### 警告色

- `--warning: #c47912`
- `--warning-soft: rgba(196, 121, 18, 0.12)`
- 用于：
  - 待审批
  - gate
  - 待处理状态

#### 风险色

- `--danger: #bf4535`
- `--danger-soft: rgba(191, 69, 53, 0.12)`
- 用于：
  - 失败
  - 终止
  - 冲突
  - 缺证提醒

#### 成功色

- `--success: #1d7f5c`
- `--success-soft: rgba(29, 127, 92, 0.12)`
- 用于：
  - 完成
  - 已通过
  - 低风险正向结果

### 3.3 用色原则

- 颜色只服务于状态与结构，不服务于装饰
- 一个区域内通常只允许一个主强调色
- 同屏高饱和色不要超过 `2` 类
- 不要把 `accent / warning / danger / success` 同时大面积铺满
- 内容越核心，越优先靠排版表达，而不是靠颜色表达

### 3.4 禁止事项

- 不要新增紫色作为主视觉
- 不要把浅底工作台做成深色科技风
- 不要用高饱和渐变铺满大面积卡片
- 不要给普通内容卡片分配不同主题色背景

## 4. 背景系统

### 4.1 页面背景

当前全局背景不是纯白，而是轻渐变浅底：

```css
background:
  radial-gradient(circle at top, rgba(223, 232, 247, 0.8), transparent 42%),
  linear-gradient(180deg, #edf2f8 0%, #f6f7f4 100%);
```

设计意图：

- 避免纯白造成的生硬感
- 保持安静、轻量、带一点空间层次
- 让卡片与分区边界更容易成立

### 4.2 面板背景

- 普通面板：`--bg-panel`
- 强输入面板：`--bg-panel-strong`

使用规则：

- 信息型卡片优先使用半透明浅白
- 表单控件优先使用更实的浅白
- 不要把每个容器都做成纯白硬块

## 5. 边框系统

### 5.1 当前边框变量

- `--border-subtle: rgba(21, 54, 91, 0.12)`
- `--border-strong: rgba(21, 54, 91, 0.2)`

### 5.2 使用规则

- 普通卡片边框用 `subtle`
- 输入框、按钮、交互触发器边框可用 `strong`
- 结构分割线优先使用 `rgba(21, 54, 91, 0.08)` 附近的更轻值

推荐层级：

- 页面分区线：最轻
- 普通卡片边框：轻
- 输入边框：中
- focus 态：通过描边光晕强调，不要暴力加粗

## 6. 圆角系统

### 6.1 当前变量

在 [global.css](/D:/feishu/agentinsight-eufy/src/frontend/src/styles/global.css:20) 中：

```css
--radius-lg: 24px;
--radius-md: 18px;
--radius-sm: 12px;
--field-radius: 16px;
```

### 6.2 建议语义

#### `--radius-lg: 24px`

用于：

- 首页主要列表容器
- 大型概览条
- `NEXT ACTION`
- 一级信息块

#### `--radius-md: 18px`

用于：

- 一般内容卡片
- 子模块容器
- 项目内信息组

#### `--radius-sm: 12px`

用于：

- 小卡片
- 列表项内部块
- 次级容器

#### `--field-radius: 16px`

用于：

- 输入框
- select trigger
- 多选 trigger

### 6.3 圆角使用原则

- 同一屏尽量控制在 `2~3` 种圆角
- 大容器圆角应明显大于内部元素
- 不要出现同层级容器圆角忽大忽小
- 不要用过小圆角做当前这种柔和浅底工作台

## 7. 阴影系统

### 7.1 当前阴影变量

```css
--shadow-soft: 0 18px 40px rgba(22, 34, 48, 0.08);
```

### 7.2 当前实际使用倾向

当前整体已在往“弱阴影”收敛：

- 普通卡片阴影很轻
- 编辑页大量移除了卡片阴影
- 结构主要依靠边框、间距和背景层次建立

### 7.3 阴影使用原则

- 阴影只用于轻微抬升，不用于制造视觉噪音
- 页面中不应同时出现多套明显不同的阴影语言
- 重要容器可以有轻阴影
- 普通列表区块优先靠边框和留白，不靠重投影

### 7.4 禁止事项

- 不要使用大而糊的重阴影
- 不要 hover 时出现明显漂浮感
- 不要用阴影模拟层级而忽略结构本身

## 8. 间距系统

当前代码还没有抽成统一 spacing token，但已经形成了较明确的实际基线。

### 8.1 常见间距档位

按当前实现，可视为以下几个常用档位：

- `6px`
- `8px`
- `10px`
- `12px`
- `14px`
- `16px`
- `18px`
- `20px`
- `24px`
- `28px`
- `32px`

### 8.2 推荐语义

#### `6px ~ 8px`

用于：

- 标签与数字之间
- 标题下的紧凑辅助信息
- 小型 cluster 内部

#### `10px ~ 12px`

用于：

- 小型按钮组
- 小块内容堆叠
- meta 信息组

#### `14px ~ 16px`

用于：

- 标题与内容之间
- 一般组件内部垂直节奏
- 常规 section heading 下方

#### `18px ~ 24px`

用于：

- 卡片内边距
- 列表项内边距
- 大块内容组的横向留白

#### `28px ~ 32px`

用于：

- 页面一级区块之间
- 首页核心模块之间

### 8.3 间距原则

- 页面优先靠留白建立结构，而不是靠更多边框
- 同一模块内部节奏要稳定，不要同时出现过多无规律 gap
- 卡片内部 padding 应先统一，再去调单个子元素
- 首页分区之间的空白应大于分区内部空白

## 9. 按钮与交互块风格

### 主按钮

- 背景：`--accent`
- 文字：白色
- 圆角：胶囊形 `999px`
- 阴影：无重阴影

### 次按钮

- 背景：轻白
- 边框：`--border-strong`
- 不做强拟物

### Hover 原则

- 只允许轻微颜色变化
- 不建议明显上浮
- 不建议出现厚重 hover 投影

## 10. 首页专用视觉约束

首页应保持“分发页”而不是“内容堆场”。

首页上的视觉层级建议固定为：

1. 顶部 summary strip
2. `NEXT ACTION`
3. `CONTINUE WORKING`
4. `RECENT ACTIVITY`

对应约束：

- 同屏不要出现过多等权重大卡片
- `NEXT ACTION` 可以更强，但不能厚重
- `CONTINUE WORKING` 与 `RECENT ACTIVITY` 必须弱于 `NEXT ACTION`
- 计数条应平，不应做成迷你 dashboard

## 11. 后续演进建议

如果后续要继续抽象设计系统，建议把下面内容正式 token 化：

- `color.text.primary`
- `color.text.muted`
- `color.surface.default`
- `color.surface.strong`
- `color.border.subtle`
- `color.border.strong`
- `color.status.accent / warning / danger / success`
- `radius.lg / md / sm / field`
- `space.1 ~ space.8`
- `shadow.soft`
